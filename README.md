# SchoolPassReader
programa feito para fins pedagógicos, o objetivo é ler a carteirinha dos estudantes para que possa fazer a contagem automática dos alunos presentes, assim como, marcar presença para eles na pauta dos professores,  a fim de otimizar o tempo nas salas de Aula, e agilizar o trabalho da coordenação na contagem de alunos, e da cantina na alimentação.
